# Pythagoras-Tree

An interactive fractal visualiser based on the Pythagoras tree. Use the controls to explore recursion depth, angle, animation speed, and randomisation; the reset control restores the visualiser.

## Open locally

Open `index.html` in a modern browser. Alternatively, from the project root, start a local server:

    python -m http.server 8000

Then visit http://localhost:8000. After changing the visualiser, try the controls and reset to review the result.

## Editing the experience

The visualiser is in the root-level `index.html`. The repository also includes the root-level audio file `music.mp3`; retain its relative path if replacing the file.
